# Калькулятор распределения средств

Статический сайт для Vercel. Никаких серверных функций, базы данных или API-токенов.

## Публикация
1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html` и `vercel.json`.
3. На vercel.com/new выберите Import Git Repository и этот репозиторий.
4. Framework Preset: Other, Root Directory: `./`, Build Command: пусто, Output Directory: пусто.
5. Deploy. После успешного размещения скопируйте HTTPS-адрес сайта.
6. В @BotFather: /setmenubutton → @fin_raspred_bot → новый HTTPS URL → «Открыть калькулятор».

Проверка: поступление 120 000 ₽ → исходящие 108 000 ₽, прочие 10 800 ₽, хозяйственные 10 800 ₽, наличные 32 400 ₽, переводы 54 000 ₽, остаток 12 000 ₽.

Сайт не размещён в каталоге, но доступен всем, у кого есть ссылка.
